Kurz gesagt

Task Board läuft vollständig auf deinem eigenen Computer. Es gibt keinen Task-Board-Server. Wir erhalten keine Daten von dir – weder deine Aufgaben noch Nutzungsstatistiken.

Deine Aufgaben

Deine Einträge werden auf deinem Computer gespeichert, als Markdown-Datei (z. B. in deinem Obsidian-Vault). Task Board schickt diese Datei nirgendwohin.

Verbindung mit Google Tasks (optional)

Wenn du Task Board mit deinem Google-Konto verbindest, damit deine Einträge in Google Tasks gespeichert werden, gilt:

  • Task Board fragt nur die Berechtigung für Google Tasks an (https://www.googleapis.com/auth/tasks), also das Lesen, Anlegen, Ändern und Löschen deiner Aufgaben und Aufgabenlisten. Auf andere Daten deines Google-Kontos greift Task Board nicht zu.
  • Die Daten werden direkt zwischen deinem Computer und Google ausgetauscht. Sie laufen über keinen anderen Server und werden an niemanden weitergegeben.
  • Die Daten werden nur dafür genutzt, deine Aufgaben in Task Board anzuzeigen und deine Änderungen bei Google zu speichern. Sie werden nicht für Werbung verwendet, nicht verkauft und nicht zum Trainieren von KI-Modellen genutzt.
  • Der Zugangsschlüssel von Google wird nur auf deinem Computer gespeichert (unter Windows verschlüsselt für dein Benutzerkonto, unter Linux in deinem Benutzerordner, nur für dich lesbar).
  • Du kannst die Verbindung jederzeit trennen: in den Einstellungen von Task Board oder unter myaccount.google.com/connections. Beim Trennen bzw. Deinstallieren wird der Schlüssel auf deinem Computer gelöscht.

Die Nutzung und Weitergabe von Informationen, die Task Board über Google-APIs erhält, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung („Limited Use“).

Updates

Task Board fragt höchstens alle 6 Stunden bei GitHub nach, ob es eine neue Version gibt, und lädt diese bei Bedarf von dort. Dabei sieht GitHub – wie bei jedem Webseitenaufruf – deine IP-Adresse. Es werden keine weiteren Daten übertragen. Automatische Updates lassen sich in den Einstellungen abschalten. Es gilt die Datenschutzerklärung von GitHub.

Diese Webseite

Diese Seite wird von GitHub Pages bereitgestellt. GitHub verarbeitet dabei technisch notwendige Daten wie deine IP-Adresse. Wir setzen keine Cookies und verwenden keine Statistik- oder Werbedienste.

Deine Rechte

Da wir keine personenbezogenen Daten von dir speichern, gibt es bei uns nichts zu beauskunften oder zu löschen. Bei Fragen schreib an die oben genannte E-Mail-Adresse. Für Daten bei Google bzw. GitHub wende dich an diese Anbieter.

English summary

Task Board runs entirely on your own computer; there is no Task Board server and we receive no data from you.

If you connect Task Board to Google Tasks, it requests only the Google Tasks scope (https://www.googleapis.com/auth/tasks) to read, create, update and delete your tasks and task lists. This data is exchanged directly between your computer and Google, used only to show and sync your tasks in Task Board, never shared with anyone, never used for advertising, never sold and never used to train AI models. The Google access token is stored only on your computer and deleted when you disconnect or uninstall. You can revoke access at any time at myaccount.google.com/connections.

Task Board's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Task Board checks GitHub for updates at most every 6 hours (GitHub sees your IP address). Contact: taskboard.fantastesy@gmail.com
