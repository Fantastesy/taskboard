Task Board

Eine Todo-Liste für den Desktop – unter Windows (mit Rainmeter) und unter Linux als Widget für KDE Plasma 6.

  • Liegt auf dem Desktop oder gleitet am Bildschirmrand herein
  • Fälligkeitsdatum, Uhrzeit mit Erinnerung, Wiederholung, farbige Tags
  • Notizen, Links, Dateien und Unteraufgaben an jedem Eintrag
  • Gespeichert als Markdown in deinem Obsidian-Vault
  • Aktualisiert sich automatisch
